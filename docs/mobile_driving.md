# 手机驾驶操作拆分

2026-10-20，源码调试版，未导出新APK。当前第六版APK仍是旧驾驶操作。

步行继续原模拟摇杆；实际驾驶时隐藏步行摇杆和步行/推车/改装/安装等动作按钮，左下左右转向，右下刹车与油门。挡位、停车/起身放在踏板上方一行。720×1280逻辑坐标：左转(28,1080,132,140)，右转(180,1080,132,140)，刹车(370,1080,130,140)，油门(530,1080,162,140)，D/R(370,980,130,72)，停车(530,980,162,72)。按钮间保留20～58px横间距，上排至踏板间隔28px，底部60px。下车还原原车辆按钮位置和步行控件。

油门按住加速、松开滑行减速；左右转向与油门手指独立，允许滑动到另一同类按钮，滑出停止，滑回重新响应；刹车优先于油门，只制动到0、不自动倒车。停稳(abs speed<=.2m/s)才能切D/R，换挡清除原按压，必须重新按油门。退出驾驶默认恢复D。暂停/切后台/失焦清除全部触摸状态，恢复不自动继续油门。

触屏专用平滑转向，3.8单位/秒转入、4.8回正，高速转向最多降到低速的48%；低速转弯随速度变化，不允许静止原地旋转。手机加速度6m/s²、倒车限速2.5m/s，原前进最高14m/s不变，刹车16m/s²。桌面WASD仍使用原规则，未替换键盘驾驶输入。

新scripts/ui/mobile_driving.gd负责布局、多手指和gear；RV增加独立触屏油门/制动/方向输入，避免与步行摇杆互相清零。main在HUD更新后重排驾驶控件；mobile_joystick.can_control不再处理驾驶移动，原动作路由仍支持停车/驾驶席起身/设置等。
