# 《萤火之路》音乐方向建议

2026-10-18 更新：本方向已用于《末日与黎明》第一轮配乐和音效接入，见 [实现记录](audio_implementation.md)。以下为当时的方向讨论。

此次只确定创作方向，不新增全局背景音乐。影片使用原声，现有燃烧声等保留。

建议核心气质：孤独、克制，仍能感到兄妹回忆与房车避难所的温暖。小萤的旅程应保留希望，不宜整场持续用惊吓式恐怖音墙，也不宜使用英雄出征般的大编制鼓点。

| 场景 | 建议音色与节奏 | 叙事作用 |
| --- | --- | --- |
| 毕业梦境 / 兄妹回忆 | 很短的钢琴或音乐盒动机，少量暖弦乐 | 建立以后能反复认出的兄妹主题；本次影片保留自身配乐 |
| 镇上探索 | 稀疏钢琴、低音持续音、远处金属或风声质感，无明显鼓组 | 留出空间听脚步、丧尸和环境；音乐间歇出现 |
| 房车内 / 湖边休息 | 同一主题的柔和版本，原声吉他或柔和钢琴，约 55–70 BPM | 让玩家听到安全与短暂安宁，避免过于轻快 |
| 被追逐 / 逃生 | 低音脉冲、轻微不规则打击，约 85–105 BPM，旋律很少 | 随威胁增强张力，危险解除后逐渐退回环境声 |

推荐先试听三段 30–45 秒的小样：镇上探索、房车夜晚、追逐。用同一段实际操作视频比较；先判断是否听得清危险，再判断旋律是否适合长期循环。镇上不必从头到尾持续播放，一点安静能让房车里重新出现的主题更有意义。

后续可采用分层音乐：探索底层 + 追击层，渐入渐出；进入房车切回温暖版本。不要每打中一次就重启音乐，也不要让车内外反复上下车造成突兀切歌。

以上为本游戏的创作建议。可参考 GDC 的 [Using Music to Build Suspense](https://www.gdcvault.com/play/1028692/-Homefront-to-God-of)：其演讲将声音设计、音乐和有意安排的安静作为营造悬念的工具。

选曲时优先委托原创或自行生成统一主题的小样；如使用现成音乐，逐首核对游戏使用、商业发行、剪辑循环及署名要求，再决定最终素材。
