# 小镇密度、街区尸群、首次补给与房车管理 · 2026-10-17

> 本页记录首版。当前包装、消耗、昼夜和货物整理规则已由 [新版实现](day_cargo_revision.md) 取代。

## 游玩流程

1. 按原剧情逃到房车，领取并装备棒球棍（仍可选择不拿）。
2. 坐到驾驶位，点「开始驾驶」后触发“初次补给”。文字说明末日生存需要食水，小地图以金色虚线及闪烁目标引导前往便利店。
3. 到店停车，起身后从右侧车门下车，进店。无需清空门外尸群；店内两只丧尸可以击倒或绕过。
4. 蓝色货架拿四瓶 500 ml 饮水，黄色货架拿三份密封面包。水每瓶 0.5 kg、面包每份 0.25 kg，放入随身背包，保留原先 10 kg 上限与超重拒绝逻辑。文字强调水很重，不能无限携带。
5. 目标切换为返回房车。坐到驾驶位，点击左侧「房车管理」，存入食水后完成任务。完成后可继续探索；若同时取得哥哥纸条，原来的回家改装路线仍保留。

## 房车管理

- 驾驶座坐下时以及户外驾驶时都能打开。面板打开会暂停游戏；关闭后恢复，避免边操作面板边误驾驶。
- 车载燃油、**仅货舱内的**饮水和食物分别显示，含可行驶距离、食水可维持时间的估计。
- 货舱按重量计，容量 **1000 kg**。逐项展示图标、单件重量、随身数量、车存数量；支持存一件、取一件、存入全部未装备物品。
- 已装备的棒球棍保留在手上。货舱满、随身超重时转移原子拒绝，不丢失物品。货舱重量包含存入的食水，不包含油箱。
- 后续区域预留「生产模块 / 舱体扩展 / 车载武器」，本轮只展示未安装状态。
- 支持在面板中保存进度。新存档保留燃油、累计里程、消耗计时余量、新手任务阶段、物品、装备、货舱及车辆位置和方向。标题页允许加载未完成的新手任务，旧版完成存档仍兼容。

## 当前平衡数值

| 项目 | 当前规则 |
| --- | --- |
| 油箱 | 容量 60 L，新游戏 6 L |
| 燃油消耗 | 实际移动 1000 m 消耗 1 L，倒车也计入；原地转向/顶墙不按油门空扣 |
| 饮水 | 活跃游玩每 240 秒消耗一瓶 500 ml |
| 食物 | 活跃游玩每 360 秒消耗一份 |
| 供给来源 | 优先随身食水，其次房车货舱；库存不会扣成负数 |
| 暂停 | 标题、过场、弹窗、管理面板、装备面板及游戏结束时不计；无离线扣除 |
| 耗尽 | 没油无法继续行驶；食水耗尽本轮不额外添加饥渴伤害 |

参数集中在 `scripts/core/game_state.gd`。面板展示的是货舱储备，随身物品列在转移列表中，不混成“车内已有”。

## 小镇与尸群

- 建筑从 278 栋增至 **343 栋**。街区内部补住宅排布，保留道路、停车坪、功能场地和剧情通道。
- 草木从约 1300 处增加到 **5089 处**（4359 处低草、625 棵单树、102 处芦苇、3 处树群）。为底层地面添加程序化细草纹理，远景不再只是纯色绿面。
- 草地与大树分开判断可放位置：小萤家周围草坪允许长草；房屋、停车坪、车道及逃生路线保留空白。额外住宅占用范围自动排除。
- 主干道分为 **57 个街区段**，通常每段最多三只游荡丧尸。按玩家/房车距离启用附近区域，远处隐藏并停用动画和物理，限制同时活跃开销。
- 区域全部清空后约 **9 秒**，从附近建筑外侧可通行位置补充。新怪避开玩家 18 米内以及当前镜头内；没有合适位置时延后尝试，不会当面突然出现。
- 首次开车后原有开场/店外尸群也纳入区域管理。店内两只独立保留死亡结果，不在玩家拿补给时无限刷新。
- 进店暂停户外敌人，出店恢复；车内仍然允许附近户外丧尸围攻已乘坐的房车。
