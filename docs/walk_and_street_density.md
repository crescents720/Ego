# 丧尸步态与街区密度调整

2026-10-17，已接入正常游戏。

## 丧尸

此前 Walk 只有很小的腿部旋转，静态源模型本身又是前后跨步站姿，追逐时显得平移。新步态使用逐帧脚部目标与两段腿部反解，明确交替支撑、摆腿、屈膝和抬脚。按源网格重新标定左右膝盖、脚踝，修正靴子、裤脚与裤腰的蒙皮归属。

- 周期约 0.95 秒，左右腿交替；实测脚踝前后运动约 44～46 厘米、抬脚约 14.6 厘米。
- 追逐速度从 1.85 米/秒调整为 0.85 米/秒，与新的拖步步幅相配；根据实际移动速度调整播放速度，受阻停止时返回待机。
- 保留伸手、上身轻晃、10 拳击倒、啃咬与受击动作。
- 实际追逐与足部骨骼轨迹由 `tools/verify_zombie_walk.gd` 检查；动画预览为 `artifacts/combat_walk.gif`。

## 居民区

普通建筑由 59 栋增至 278 栋，仍复用原有 5 种轻量建筑，沿道路两侧连续排列，替代草地中央分散的摆放方式。沿街排列节距约 11.5 米，依建筑宽度形成约 1～3 米为主的缝隙；全镇最近墙面间距中位数实测约 3.02 米。建筑朝向随街道调整，连续地块底面加强街墙感。

保留道路、人行空间、家宅/后院/逃生通路、便利店入口，以及全部功能建筑预留地块。基于实际模型包围盒排除相互重叠和占路的建筑。可进入的建筑仍以现有家宅开篇、房车和便利店为准，新增普通建筑没有交互。

继续使用距离显示范围，建筑遮挡检查改为共用每帧的三条人物视线，避免楼栋增加后重复计算相机投影。手机真机性能尚待验证。

## 验证

- `verify_street_density.gd`：278 栋，墙距中位数约 3 米，无建筑相互重叠。
- `verify_town.gd`：房车实体碰撞走通外环、主街和支路，功能地块与湖岸边界正确。
- `verify_building_occlusion.gd`：新密集街区遮挡淡化和恢复。
- `verify_opening.gd` / `verify_store_entry.gd`：开篇逃生、后院驶出、便利店进出。
- `verify_actor_models.gd` / `verify_combat.gd` / `verify_combat_skin.gd`：追逐、啃咬、10 拳击倒、蒙皮变形和原有上下车路径。
