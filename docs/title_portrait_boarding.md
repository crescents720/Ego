# 标题页、手机竖屏影片与上车过渡

2026-10-17。

- 正式名称更新为《末日与黎明》。独立标题页使用用户提供的完整图片，标题位于上方，三个触屏大按钮为“新游戏、加载存档、退出游戏”。不显示玩法 HUD。没有现有可加载存档时加载按钮置灰；加载沿用现有首日完成存档机制，本次没有扩展任意位置存档。
- 新游戏按钮直接开始影片。影片输出与游戏一致的 720×1280、9:16；主体完整保留为 720×960，上下用同一画面的暗色柔化背景补齐，避免拉伸人物或裁掉原图内容。来源标识保留。转换脚本同步更新。
- 停用所有后加的合成对白；字幕、影片原声、燃烧等环境音保留。旧图片版的对白推进改用定时，避免依赖已停用的语音完成信号。
- 进入房车时立即设置最终室内相机，取消从地图向室内远距离插值的旋转、推近效果；保留玩家之后手动拖拽旋转与缩放。停止驾驶返回车内也直接使用最终相机。
- 侧门上车用约 0.48 秒的现有 Walk 骨骼动作配合角色视觉位置向车内移动 0.4 米，再回到 Idle。角色碰撞根节点仍在安全的门内落点，避免门框阻挡导致动画卡住。车辆不旋转，结束后恢复自由移动；下车或入座会取消尚未完成的过渡。
