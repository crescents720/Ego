# 影片开场与丧尸游荡

2026-10-17。

## 叙事调整

用户提供影片 `ff5416069efe484883df0caaad39fee4.mp4`：15 秒，832×1108，30 帧，带原声。画面从夜间熟睡进入兄妹毕业合影，再出现裂纹和火中惊醒。运行时保留完整画幅、原声和“AI生成”来源标识，转为 720×960 的 Theora / Vorbis 视频。原 MP4 不修改，记录原文件 SHA256。

新游戏：影片 → 1.8 秒拿钥匙的黑场过渡 → 屋外前门被围的短观察段（5 秒，可提前继续）→ 玩家沿地面虚线逃至房车。影片已经表现惊醒，因此不再重复旧的图片对白、破碎图片及 3D 卧室起身。过场使用影片自己的声音，原占位配音与梦境音乐暂停，避免叠音。进入屋外后保留原来的独白与燃烧声。

播放按钮位于影片下方，章节标题位于上方；完整画幅不裁切、不被字幕和按钮覆盖。跳过影片后仍交代钥匙和屋外困境。播放结束或跳过时停止解码并释放视频流。没有影片资源时保留旧开场，也可由 `opening.start(false)` 明确启动备用版本。

转换脚本：`tools/prepare_opening_video.ps1`。Godot 视频播放采用内置 OGV 支持，见 [官方说明](https://docs.godotengine.org/en/stable/tutorials/animation/playing_videos.html)。手机真机解码性能尚未测试。

## 丧尸游荡

没有目标、目标进入室内或离开警戒距离时，丧尸以当前位置为中心，在 2.8 米内随机选点。每秒约 0.43 米，使用现有 Walk 骨骼动作，转向更慢，间隔随机短暂停留并播放 Idle。选择路线先检测墙体，实际移动仍经过物理碰撞；被障碍卡住时重新选点。追击优先于游荡，重新进入警戒范围立即恢复追击，啃咬仍检查目标有效性与距离。

验证：`verify_opening_film.gd` 图形模式实测启动、跳过、重播、15 秒影片真实解码与自然结束、屋外交接；截图 `artifacts/opening_film.png`。`verify_zombie_wander.gd` 检查无目标、目标失活、远距离丢失、局部活动边界、Walk / Idle 切换与重新追击。备用开场及首日流程另行回归。
