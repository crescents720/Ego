# 房车比例、停车场通行与开篇逃生调整

2026-10-17。

- 房车外部统一缩到原来的 75%，包括不透明车顶、轮组和改装件。碰撞体为 2.175 × 1.8375 × 6.375 米；按轮底保持原地面高度。室内保持人物可行走尺寸。
- 外部门点随模型缩放，局部坐标为 (1.1175, 0, -0.7875)。下车点保留 0.66 米人物净空，四个车身朝向与出口受阻检查均通过。
- 户外默认正交视野由步行 18 / 驾车 25 调整为 15 / 20。现有滚轮、双指和按钮缩放，以及独立的小地图缩放保留。
- 278 栋普通街区建筑取消覆盖整块地皮的盒状碰撞。五种模型各共享一个贴合真实墙面的静态三角形碰撞资源，排除高度低于 0.35 米的停车地面和低路沿；建筑实体保持碰撞。功能建筑及别墅的碰撞独立保留。
- 屋外过场沿用正式玩法的相机方向、位置偏移和视野，交接时不反转。
- 前门丧尸增加到 16 只，散布在街上不同位置。过场中小萤不受攻击；恢复操作后群体立即开始追击，能够啃咬，追击到屋后时绕过房屋侧面。它们独立分组，不增加便利店清理任务数量。
- 删除逃生圆环，改用贴地金色发光虚线，亮度沿路线流动，走过的部分逐渐隐藏，上车后整条引导消失。
