# 工厂、铁丝与车床

2026-10-19，源码调试版；按用户要求本轮不导出APK。第五版APK不含本功能。

## 玩法

工厂位于小地图“工厂”预留地，中心(-66,250)，已添加从西侧公路进入前院的支路。正门朝向普通游戏镜头，靠近卷帘门按E/交互，卷帘上升后进入车间。门前交互离开，可推车进出；松开的推车留在所在房间，不能隔空取货。

车间使用近距离第三人称跟随镜头。电脑右键拖动，手机右侧空白区域拖动转视角，左侧摇杆照常移动，支持独立手指；近墙用射线缩短镜头距离，避免墙体穿模。门口“离开工厂”优先级最高。车间内不能驾驶或保存，外出后可按原规则保存。普通菜单暂停时清除镜头拖动，并暂停室内丧尸。

每次进入生成2～3只普通丧尸，退出清理本次敌人，不积累尸群。击杀仍可掉落现金并步行拾取。室内直接使用原模型砖墙、高窗、水泥地及通高屋顶，保留约10×15米可用面积和约7米高度，添加简单灰绿生产线与照明，主通道留给推车。

铁丝首次4份，每份0.5kg。之后每45秒世界时间补充1份，最多6份；不足45秒不会因进出补货，时间余数保留。未拾取的数量保留，重新进厂会重新布置其位置；睡眠推进世界时间也计入。地面使用Wire_Mesh模型、细圈和文字提示，靠近交互收集。附近推车有空间时优先放推车，否则放背包；两者满则拒绝并保留掉落。

生产线上有一台24kg车床，每局只可取走一次。须把推车带到附近，至少空出24kg，才能交互装运；不能放入10kg背包。推车25kg上限仍独立计重，因此空车最多可装车床与2份铁丝。推车继续使用现有降速、松手战斗、门口装卸收车流程。

运回房车卸到货舱后，靠近“基础维修台”交互并确认安装。货舱扣除车床，在维修台显示实物，安装状态保存。当前只安装车床、存储铁丝，尚未做铁丝网加工或车身加固。

## 文件与资产

scripts/environment/factory.gd管理入口、分离车间、镜头、刷新、装运与安装；GameState经济存档添加factory_wire/factory_refresh_at/lathe_taken/lathe_installed，仍兼容schema5。原有存档默认未访问工厂，不改用户存档。推车、现金掉落采用房间编号0街道/2便利店/3工厂区分，防止跨房间显现或拾取。

用户提供Downloads中的Sewing_Factory.usdz、Wire_Mesh.usdz、Desk_Lathe.usdz原件保留。tools/build_factory_assets.py转换、内嵌纹理并将工厂原封闭卷帘门几何切出入口，输出assets/factory/factory_open.glb、wire.glb、lathe.glb。工厂4564三角面、车床7407、铁丝4，无需破坏性简化。外壳原件factory.glb保留；车间保留原模型内部；前轮误判仅有外壳而用简单盒子替代，现已纠正。仅生产线与新增照明使用简单几何。

## 2026-10-19 原模型内部纠正

用户指出车间偏小。通过inspect_factory_interior.gd直接进入原始factory.glb查看多个角度，确认原件是约10×15m、7m高通高厂房，内部具有两层高度的砖墙和窗、水泥地、屋顶，前轮“只有外壳”的判断错误。已移除自制10×14×3.8m矮盒子，room/OriginalFactoryInterior使用未修改原转换模型，平移SHELL_OFFSET(1.85,0,1.67)，不缩放。依据实际内墙平面x±4.74、z±7.20制作不可见碰撞，未用装饰柱最外沿当内墙；这样近墙镜头不会穿进原卷帘门。室内入口改为(-.9,1.05,4.9)，生产线增加到两列三组，车床在(3.1,1.13,-1.3)，铁丝重新分布。

还纠正了外门几何切口：原门实际z5.6～5.7，旧切口z6.3偏外；新cut x[-4.96,-.94]、y[.10,2.75]、z[5.45,5.90]，卷帘同步3.98×2.55m放在真正门面。原始USDZ和未裁切factory.glb保持不变。

verify_factory再次通过，Vulkan截图factory_inside/factory_entry_original与原件检查factory_original_inside_*已核对。没有导出APK。

镜头补充：出生点放入车间内侧，避免一进门就被门面挤到头部；极近墙时角色淡出防止头发堵住镜头，离开工厂恢复不透明。
