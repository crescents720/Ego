# 车床生产与四面铁丝围栏

2026-10-19，源码调试阶段；本轮未导出APK。

## 入口与生产

当前唯一安装位为房车内用户圈出的基础维修台。工厂取得24kg车床、推车运回并卸进货舱后，在此交互确认安装，货舱扣除一台并显示车床。其他家具没有安装入口。已装车床时再交互，打开“工作台 · 车床生产”，显示货舱材料数量、耗时、产品、四面防护及当前任务。焦点名称同步为“车床 · 生产铁丝围栏”。

初始配方为可调整参数：前/后各铁丝4份（2kg）、20秒；左/右各6份（3kg）、30秒。铁丝只从房车货舱扣除，背包与推车里的材料须先卸入。每次加工一面，仅允许一个任务，已安装且仍有耐久的一面不能重复生产。材料在开始时一次扣除，任务截止时间用世界时钟保存；关闭菜单后运行，暂停菜单不推进，休息快进也计入。完成直接安装到所选车身侧，无中间可重复领取物品，并显示完成提示。

生产界面使用暂停的固定宽面板，720×1280下边界(24,100)+(672,1080)，文字完整。关闭后继续探索或驾驶，任务不会因为离开车床中断。

## 防护与修理

前、后、左、右每面500点耐久，每次真实丧尸攻击命中对应一面扣1，阻挡本次全部车体伤害。保留原攻击前摇、距离与遮挡验证。第500次击毁该面，本次仍被吸收；后续攻击再伤及车体。撞车及其他非丧尸伤害仍按原规则伤车，不会被围栏吞掉。根据丧尸在车辆局部坐标的方向分配侧面，随车旋转。

有耐久的围栏在车外显示、击毁隐藏。围栏是附着车身的防护模块，不是可单独放置在地面的路障，不新增阻塞车门/玩家的物理墙。高度约1m，在射击口下方，左右各三段、前后各一段。

修车厂允许“车体满血但围栏受损”时检修。既有12秒现场维修过程同步修复仍有耐久的围栏；中断保留已修复部分，完成恢复至500。耐久已经为0的围栏绝不因维修重生，需要重新生产。房车修复仍保持免费现场操作。

## 视觉修改

工厂铁丝保留原模型、黄圈和名称，额外加蓝白色动态光柱与脉动闪点，不增加实时灯光负担，拾取/刷新随原掉落节点一并清理。

窗边常驻文字与家具名称改为“左侧窗口 / 右侧窗口”，去掉M60限定；当前机枪功能与gun_left/right内部ID保留，射击状态仍显示实际使用的武器。

用户提供Wire_mesh_fence_Low_Poly.usdz原件保留，build_fence_asset.py转换至assets/factory/fence.glb，4366三角面，尺寸约2m长、.98m高。源贴图JPEG网眼以白底表示空隙，不能直接当不透明挡板；转换器恢复alpha覆盖，运行材质用同类菱形网格及屏幕导数保持远处可见，补少量边框。使用原模型几何，没有生成新的位图素材。
