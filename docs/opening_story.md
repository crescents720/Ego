# 序章：萤火未熄

已接入“开始新游戏”。设计与实现记录：2026-10-17。

序章先让玩家认识兄妹之间的亲近，再让同一辆房车从“毕业旅行的约定”变成“逃生的唯一机会”。哥哥在现实中没有出现；小萤带着这个疑问离开家，接到便利店搜寻物资与哥哥线索的现有首日流程。

## 分镜与玩家体验

| 段落 | 画面、声音 | 玩家操作与转场 |
| --- | --- | --- |
| 1. 熟睡 | 小萤躺在卧室原模型的床上，斜俯视镜头；字幕“梦里，是一个再普通不过的春天。” | 约 2.6 秒后进入梦境，也可点“继续”或按 E。 |
| 2. 毕业合影 | 使用用户提供的兄妹合影；暖色背景、轻柔钟琴与中文对白。哥哥祝贺毕业，小萤笑着要求重拍，哥哥提起房车旅行。 | 对白顺次播放，也可推进；右上角可跳过过场，直接来到屋外。 |
| 3. 梦境破碎 | 合影分块错位、裂缝逐渐显现并变暗；哥哥的声音降调，低通与混响逐渐增强，像隔着水远去。 | 约 2.6 秒后惊醒。 |
| 4. 火中惊醒 | 回到卧室，床周围出现黄色火芯、橙色火焰、烟雾与闪动火光，并播放燃烧声。 | “起身逃离”按钮 / E；小萤起身，字幕交代拿走钥匙，然后淡出。 |
| 5. 家门被堵 | 直接切到 American House 外观。屋顶、窗边冒火，16 只丧尸错落围住前门；后院可以看见房车。 | 短暂观察与独白；点“从后院逃走”或按 E，也会自动结束这一镜头。 |
| 6. 后院逃生 | 保持同一 45°镜头，恢复移动控制后丧尸开始追击；贴地流动的金色虚线引导玩家从屋侧绕到后院。此段隐藏攻击按钮，强调逃离。 | WASD / 触屏方向移动，到房车右侧中部门按 E / 交互上车。 |
| 7. 接入首日 | 金色指引消失，进入已有房车内部。 | 走到驾驶位，启动房车，沿侧车道驶上主路，前往便利店。 |

## 主要对白

哥哥：“哈哈，小萤，看镜头。三、二、一！毕业快乐！”

小萤：“哈哈哈，哥哥，你刚才又没看镜头！再拍一张。”

哥哥：“好，再拍一张。等你收拾好行李，我们就开着房车，一起去看看更远的地方。”

梦境破碎时，字幕只留下：“我们就开着房车……一起去……”

小萤惊醒：“哥？好烫！失火了！”

屋外：“前门，全是那些东西。哥哥，你到底去哪儿了？后院的房车，钥匙还在我这里。”

哥哥的位置与失火原因暂不解释，为后续线索留出空间。房车钥匙在起身字幕中交代，不额外增加一个可能打断紧迫感的搜寻任务。

## 模型、声音与性能

- `Bedroom.usdz` 原始约 215 万三角面。运行时保留原床、枕头与被褥，清除重复和退化面并简化到约 9,195 三角面，约 2.50 MB；墙、地板与床边家具采用简单几何体重搭。完整转换中间文件不用于运行场景。
- `American_House.usdz` 转为约 17,613 三角面的 GLB，替换原家宅外观，并配有简单碰撞体。室内离开时直接切屋外，不制作整栋别墅内部。
- 火焰使用粒子、透明着色器、烟雾与无阴影闪动灯；卧室离开后停止处理，屋外火源在玩家远离或进入室内时停用。
- 中文对白目前是本地合成的占位配音；有毕业笑谈、梦境钟琴与燃烧音效。可后续替换真人录音而保留播放与失真流程。
- 合影保留原图，包括原图自带标记。破碎通过游戏内着色器实时生成。
- 起身是角色整体姿态过渡，当前没有制作专用骨骼起床动画；火焰是叙事效果，暂不增加烧伤、倒计时或失败惩罚。

## 实现与验证

主要控制：`scripts/story/opening.gd`；火焰：`scripts/environment/story_fire.gd`；主地图接入：`scripts/main.gd`。

`tools/verify_opening.gd` 验证：新游戏从熟睡开始、照片与对白、音频失真、火焰、起身与直接切场、16 只前门丧尸、步行绕行碰撞、房车正确侧门上车、接入驾驶任务，以及房车沿侧车道驶上主路。前门丧尸单独分组，便利店仍只要求清理原来的三只丧尸。

`tools/capture_opening.gd` 可分别生成 sleep / dream / break / wake / exterior / escape 的实际渲染截图。原有自动冒烟测试保留快速进入玩法的入口，正常标题“开始新游戏”播放序章。
