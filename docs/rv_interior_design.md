# 房车内部：初始状态设计

## 设计目标

初始房车不是豪华住宅，而是哥哥与小萤共同使用过的紧凑生活舱。它需要同时满足“现在可以生活”和“以后可以不断改造”两个目标。因此固定结构只承担通行、供电和承重，生产设施尽量以可替换模块存在。

美术语言采用原创的暖冷对比：米白车壳与浅木台面体现生活感，深色金属骨架与青色接口体现工业扩展性，橙色织物与灯带提供末日环境中的安全感。顶棚采用可拆卸横梁和开放式剖面，适合竖屏俯视镜头。

## 初始空间

模型按移动游戏可读性进行约 20% 的横向与通道放大，外观模型后续也应据此同步调整。

| 区域 | 初始功能 | 后续方向 |
| --- | --- | --- |
| 前部睡眠舱 | 双人床、床下抽屉、哥哥的照片 | 医疗休息、恒温舱 |
| 左侧厨房 | 水槽、电磁炉、小冰箱、吊柜 | 净水、温室食品加工 |
| 右侧卡座 | 用餐、阅读、临时床位 | 无线电与地图桌 |
| 后部维修台 | 手工具、基础终端、任务灯 | 武器台、3D 打印和弹药加工 |
| 玄关储物 | 衣柜、医疗箱、生存箱 | 消杀气闸、外骨骼挂架 |
| 电力柜 | 初级电池与状态面板 | 发电机、太阳能与高压母线 |

中央通道保持完整，任何升级都不能侵占至少 0.72 米的行走宽度。

## 扩建接口

运行时模型内置四个带语义信息的空节点，并通过 glTF extras 保留：

| 接口 | 类型 | 默认用途 |
| --- | --- | --- |
| `SOCKET_FLOOR_CENTER` | 地板模块 | 制造设备或大型储物 |
| `SOCKET_WALL_LEFT` | 左墙模块 | 医疗、储物或水处理 |
| `SOCKET_WALL_RIGHT` | 右墙模块 | 生活设施或通信设备 |
| `SOCKET_CEILING_REAR` | 顶棚模块 | 无人机吊架或机械臂 |

Godot 包装脚本 `scripts/environment/rv_interior.gd` 暴露 `get_module_slots()`，以后升级系统应读取这些接口，而不是在主场景中写死位置。视觉模型和粗略碰撞分离，增加杯子、工具、线缆等小物件时不需要重建行走碰撞。

## 资产工作流

1. 在 Blender 中编辑 `source/rv_interior_initial.blend`，保持对象名称和四个 `SOCKET_*` 空节点不变。
2. 如需完整重建，使用 Blender 后台运行 `tools/build_rv_interior.py`。
3. 导出结果覆盖 `assets/models/rv_interior_initial.glb` 后，让 Godot 自动重新导入。
4. 用启动参数 `--capture-interior` 生成竖屏检查图 `artifacts/rv_interior_godot.png`。

当前模型有 192 个独立网格；源模型基础面约 4,200，导出时会应用圆角修改器。运行时 GLB 约 1.7MB，适合作为手机端初始主基地继续迭代。

## 镜头、遮挡与交互规则

- 室内移动使用当前相机的水平前向与右向，因此旋转镜头后方向键仍然符合屏幕方向。
- 电脑端使用空白区域拖拽旋转、滚轮缩放；手机端使用单指拖拽与双指捏合。
- 顶部结构梁在室内俯视模式隐藏。镜头位于右侧时隐藏右侧墙框，转到左侧时隐藏左侧墙框；前后端墙也按照相机所在半区切换，从而保留剖面感并减少死角。
- 冰箱、衣柜、电力柜、厨房、卡座、维修台、物资箱、睡眠舱和急救箱拥有独立交互锚点。最近且进入范围的模块使用轻微暖色材质叠层高亮，主界面同时显示模块名称。
- 模块视觉、交互锚点和碰撞相互独立。未来替换模型时只需保持前缀或更新 `INTERACTIVE_MODULES`，不需要改动相机和角色控制逻辑。

## 驾驶舱与角色（2026-10-16）

车头位于本地 -Z，驾驶舱延伸约 2.4 米。双座、方向盘、仪表台、踏板和前风挡已接入；驾驶座与站立位置由 MARKER_DRIVER_SEAT / MARKER_DRIVER_STAND 标记提供。座垫标记转换到角色中心时加 0.52 米，以匹配现有 Sit 动画骨盆高度。角色使用带蒙皮的 Idle / Walk / Sit 模型。近侧顶棚 LED 灯带随剖面隐藏。详细验证与接续范围见 home_handoff.md。


## Bounder 右侧门适配

运行包装脚本现以右侧门为唯一室内上下车口，不再使用旧 MARKER_ENTRY 作为出入口。外车门本地 +X、Z=-1.05；室内车头为 -Z，以车长比例对应到右墙 Z=-2.41。门旁生成门板、窗口、门框、地面门槛和“右侧车门 · E 下车”提示；靠相机侧门板随墙体剖面隐藏，提示保留。

原始 GLB 保留不变，运行时把衣柜移到左前角并缩窄维修台，急救箱移到左墙，右侧物资箱略向驾驶舱移动；同步更新家具碰撞及交互锚点，为侧门留出通道。该布局适配由 `_adapt_side_door_layout` 管理。驾驶停车先返回驾驶舱，再经侧门下车，车外落点使用车辆变换计算。
