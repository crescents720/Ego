# 大太刀与寺庙：第一批动作模块（2026-10-21）

## 2026-10-21 第二次动作重做（当前版本）

用户指出第一版手臂穿模且挥剑缺乏自然逻辑。第一版“握点检查通过”不足以证明表面不穿插；以下修正取代旧动画及旧时长描述。

根因：原角色部分前臂表面被绑到躯干，一部分躯干/衣服又带有手臂权重；只约束两只手腕无法约束实际手部表面。新增tools/repair_hotaru_arm_skin.py，按模型真正分离的两条手臂、两只手网格重新绑定，纠正肩/肘/腕/手指位置，更新逆绑定与已有动画的平移轨道。中立网格保持原样。鞋底也改为随本脚整体运动，去掉踏步时被拉长的三角片。修正应用在当前hotaru_sword.glb；原workshop及用户模型不覆盖，机枪专用替身保持原来源。

动作改为手掌空间握柄：右手在前、左手在后，相隔11.5cm，双腕位于刀柄两侧；不再把手腕中心当成握持中心。双腿IK和前后站姿支撑转髋，第一次斩击下小幅前踏、重心跟随、末尾撤步收势。握点随躯干平移，避免身体前移穿进前臂。刀身平面跟随各次斩击方向，横斩会转刃。不同斩击使用不同蓄力/落刀/停顿时间，收势受身体碰撞检查约束。

当前时长：1/2/3/4/5段分别为1.00 / 1.49 / 2.03 / 2.66 / 3.56秒。命中元数据为0.432 / 0.945 / 1.468 / 2.072 / 2.796秒。实际玩法依然只启用第一刀；挥动声0.36秒、接触0.432秒、1秒恢复。攻击伤害等未变。

验证：verify_sword_surfaces.py读取实际GLB并逐帧计算蒙皮后的前臂/手部表面，检查胸腹和头部保守核心体积，不再只看腕骨点；七个Sword动画均未进入检查体积。此测试不等同于任意衣服褶皱的精确三角网格碰撞检查，另检查实际双视角渲染。verify_sword验证手掌握点、当前单段伤害和时序、遮挡、装备及保存；equipment/manual_fabrication/trolley_doors回归通过。棒球棍实际画面也复查。
