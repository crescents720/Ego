# 手机摇杆、便利店出口、封面与应用图标 · 2026-10-18

新版 APK：`builds/android/FireflyRoad-0.1.20261018.2-arm64-debug.apk`，版本 code 2，约 208 MB。包名及调试签名沿用上一版，可直接覆盖安装；不需要卸载手机旧版。

## 本轮改动

- 原样替换 `assets/ui/title_background.png` 为用户调整后的封面；桌面和安卓共用。新增 `assets/ui/android_icon.png`，使用用户提供的手机图标，配置普通图标和自适应前景/背景，交由 Godot 生成各分辨率图标。
- 安卓及触摸屏使用左下固定式模拟摇杆，带死区、力度和八方向/连续方向控制。斜推可同时加速和转弯，下拉倒车。桌面非触摸模式继续保留原方向按钮及 WASD/方向键。
- `mobile_joystick.gd` 按触摸手指 ID 管理摇杆和右侧动作键，绕过只支持主手指的鼠标模拟限制。可在保持方向时用另一手指交互、攻击、上下车。坐到驾驶席时隐藏步行摇杆，但右侧“开始驾驶”和起身仍能操作。
- 人物和车辆接收独立的 `touch_move` 向量，与键盘输入合并；触摸输入不模拟键盘按下。手指移出摇杆后松手、暂停、失去焦点都会清零，避免卡住油门/走路。
- 原便利店出口使用出生点周围一米球形范围。现在统一使用正门前过道的水平区域 `Rect2(-3.5,2.15,7,1.45)` 判定，不再因离出生点偏远或高度差而无法退出；提示与交互共用 `is_near_exit()`。在该区域按钮明确显示“离开便利店”，并优先执行出口，不会选中附近货架。

## 验证

`tools/verify_mobile_input_store.gd` 使用 Godot 输入分发的真实 `ScreenTouch` / `ScreenDrag` 事件，验证：人物斜向移动；车辆同时加速和转向；第二根手指动作不重复、不打断摇杆；区域外松手和暂停清零；选择食物和水、任务切换后仍可触摸出店；坐在驾驶座时仍可触摸起身和开始驾驶。

`verify_store_entry.gd` 和 `verify_store_navigation.gd` 回归通过，保留原有门口优先级、货架通道及桌面键盘操作。图形检查：`mobile_cover_revision2.png`、`mobile_joystick_walk.png`、`mobile_store_exit_zone.png`。

最终包签名与上一版一致，APK 签名及 16 KB 对齐验证通过；Android API 37 模拟器安装启动成功，已实际检查新封面及拖动中的摇杆。另使用隔离测试存档（已取得水和食物、任务第3步），在最终 APK 中触摸进入便利店、用摇杆移动到远离原出生点的门前过道，再触摸“离开便利店”，成功返回街道；该过程日志无脚本错误。APK 内导出的图标也已提取核对。准确字节数、SHA256 和原图一致性见 `builds/android/build_info-revision2.json`。真机触感及性能仍需玩家手机确认。

测试使用禁止保存或隔离的测试数据，不覆盖电脑玩家存档。安卓测试使用单独的只读模拟器实例；测试用存档只放入该模拟器，未写入真实手机。
