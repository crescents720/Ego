# 推车进出与室内保留修复

2026-10-19，源码修复，不导出APK、不重置玩家存档。

推车在门前而小萤仍在后方时，旧判定仅取角色位置，且HUD末尾的推车分支会隐藏已经显示的进门按钮。现在cargo_trolley.doorway_points将步行角色和正在推动的近旁推车中心、前沿及两个前角合并用于门口判定；松手后的远处推车不参与判定。便利店/工厂入口与出口统一使用这些点，武器店入口也采用组合范围。门口进出优先于松手，松手仍有独立推车按钮。

室内推车消失的根因是房间编号使用int(x/1000)截断：工厂原点3000，停在左侧x2998就被错误归为2号便利店；便利店原点2000的左半也会出错。位置和货物实际没被清掉，只是显示条件错误。改为GameState.spatial_room_id取最近房间中心，推车与现金掉落均共享此逻辑。街道0、房车1、便利店2、工厂3。在室内松手后离开，坐标、角度、货物保持原值，再进入显示并可接着推走。无需对已有坐标进行迁移。

verify_trolley_doors完整覆盖：小萤在原入口范围外但推车先到的便利店/工厂入口提示和交互、推车先到出口、松手推车不远程触发入口、工厂左半停放推车及货物两次重新进入、重新推行带出、便利店左半停放/重入、室内停放状态隔离存档往返。新增测试通过；verify_factory、verify_cart_mobility、verify_mobile_input_store、verify_fabrication回归通过。测试存档user://trolley_doors_test/slot.cfg与其他测试路径隔离，未改玩家存档。
