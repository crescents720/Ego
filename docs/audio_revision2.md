## 音乐与脚步

- 保留用户当前音量滑块设置，背景音乐播放基准从 -18 dB 提升到 -10 dB，即提高 8 dB；用户设为静音时仍保持静音。
- 换用 GboxMikeFozzy 的实际步行录音与 Fantozzi 的草/沙地脚步，裁去长尾、滤波，降低素材峰值；落脚播放从 -18 dB 降至 -26 dB。
- 从按 1.65 米距离触发，改为 Walk、BatWalkL、BatWalkR 动画方法轨：周期 0 与 50% 两次落脚。当前动画周期一秒，约每半秒一步。停住、撞墙无实际移动、坐下、睡眠、攻击和上下车过渡不空响。
- 专项实际移动 2.1 秒检测到 4 次脚步；三个步行动画各有两个落脚标记。没有另设不随动画变化的固定频率计时器。

## 车辆和近战

- 点火使用 looneybits 的真实发动机启动录音，启动后约 1.1 秒淡入机械发动机循环。循环换用 qubodup 的实录；不以此延迟玩家驾驶控制。
- 撞丧尸使用独立 `ram_flesh`，由 Independent.nu 肉体打击录音混合成钝击/短脆响，同时独立触发丧尸死亡叫声。撞墙仍为金属碰撞，两类不共用音效。
- 去掉急减速时的合成单音，避免高速撞击时又叠上类似得分的音调；车辆危急和生命危急也不再用原先的单音警示。
- 挥棒换成 artisticdude 实际木棒挥动录音，在动作挥出约 0.30 秒触发；0.40 秒确认接触才发肉体命中声。挥空只有挥动声。徒手挥动在 0.12 秒、接触在 0.24 秒。
- 丧尸增加独立 `zombie_hurt` 与 `zombie_die` 录制叫声，不再以普通低吟或落地闷响替代；声音节点不依附即将销毁的丧尸，死亡后仍能播完。

## 蛍的配音和受伤呼吸

- 使用 AuraVoice 发布的真人女性非语言受伤表演，三段受击变化；倒下使用同一演员的惊叫，撤掉原来的界面死亡单音。身体落地声延后到倒地演出约 1.1 秒。
- 黄血（生命 >0 且 15%～50%）与红血（>0 且 <15%）分别使用两组不同强度的喘息。原料为 Joseph SARDIN 录制的女性呼吸，与 AuraVoice 的短痛声混合；没有用振荡器模拟人声，也没有用夸张变调制造角色嗓音。
- 中伤较轻且间隔更长，重伤更明显、间隔更短。受击叫声优先，呼吸让开；恢复到健康、死亡、暂停、过场或睡眠时停止。驾驶中受伤状态仍可听到人物反馈。
- 这是公开许可演员素材的选配和混音，不是专门为蛍录制的角色配音。最终声线和情绪是否适合角色，需要通过实际试听评价，自动触发检查不能替代这一步。

## 拍打车辆的前摇

丧尸近车后播放独立 VehicleAttack：双臂抬起蓄力，再向车身落下，整次约 1.15 秒。接触时间为 **0.60 秒**，之前不扣耐久、不播车身撞击声；每次只结算一次。目标变更、玩家下车或车辆脱离攻击距离，会使本次接触失效。攻击人物继续使用原来的 0.44 秒啃咬接触。

前摇开始仍会通知睡眠系统和存档安全检查“受到攻击”，使睡眠中的蛍及时醒来；通知不扣耐久。

## 修理厂

修车不再检查、收集或消耗维修材料。将房车停入黄色检修位，蛍在修理厂现场（包括车内）即可通过“开始检修”恢复耐久；保留停车、未被围攻、车未彻底摧毁等要求。人在远处不能遥控检修。

旧背包中维修材料与首日装甲改装原型仍保留，不删除用户已有物品；它们不构成修车门槛，也不在检修时扣除。
