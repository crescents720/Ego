# 小镇道路与普通建筑：第一批实现

2026-10-17。依据已确认的总体规划制作，已经接入正常游戏主地图。

## 当前已完成

- 约 500 × 600 米地面，包含湖泊和外围空地。
- 西、东两侧外环与南北连接路；启动街保留原坐标，另设中部纵向联络路、西侧住宅支路和多条横街。主路宽 10 米，支路宽 7 米；普通路沿暂不设碰撞，避免房车被小台阶卡住。
- 北、南出镇方向和地图边界。删除启动街原有封路位置，将封路移至新道路尽头；房车活动范围同步扩大。
- 从用户提供的 CCity Building Set 1 中提取 5 种低层建筑，实例化为 278 栋不可进入的普通街区建筑，替换之前的高大背景楼。单个模型约 212～786 个三角面，1～2 个材质，高度约 5.1～7.4 米。
- 每栋具有简单实体碰撞，沿用人物/房车被建筑遮挡时的淡化处理；远处普通建筑采用 145 米显示范围。总览截图工具会临时取消距离限制。
- 五金店、工厂、医院、警局、武器店、加油站、取水点、码头、营地均留空，仅用地面和文字标出预留地块，没有新增交互。
- 东侧湖面基础形状、岸边干路、通往湖边的支路，以及阻止步行和车辆直接进入水面的碰撞边界。树带是轻量示意，湖水和植被尚待后续美术细化。

开篇的家、后院房车和已有便利店不移动。其余功能建筑位置可在后续导入正式模型时小幅调整，道路与转弯先保持畅通。

## 验证

`tools/verify_town.gd` 使用房车实体碰撞体实际遍历外环、纵横干道和住宅支路，检查预留地块无普通建筑占用、建筑高度、湖面碰撞及异地停车不会触发便利店到达。

`tools/verify_opening.gd` 检查开篇全部阶段、绕屋逃生、侧门上车、房车出后院接入主路；`tools/verify_store_entry.gd` 检查实体走近便利店与交互进入；`--smoke-test` 检查原有完整首日闭环。

`tools/verify_building_occlusion.gd` 的采样点已改到新住宅实际后方，验证淡化与恢复，避免沿用已删除高楼附近的旧位置。

这些是电脑端原型验证，尚未完成手机真机性能验收。当前重点是路网、空间和后续建筑占地，庭院、路口细节、停车标线、湖岸景观等留待后续细化。

后续密度调整：已由最初的 59 栋增加为 278 栋沿街建筑，见 walk_and_street_density.md。
