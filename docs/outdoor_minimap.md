# 户外小地图

2026-10-17。已经接入正常 HUD，位于任务栏下方的右上区域，避免遮住任务与资源信息。

- 步行跟随小萤、驾驶跟随房车；中心金色箭头指示相应角色/车辆的朝向。
- 固定规划北向（世界 +Z 向上），不随主镜头旋转。
- 道路、湖面、普通建筑轮廓和预留地块直接读取当前 TownLayout 数据；家与已有便利店独立标记。
- 金色“家”、青色“店”为已有地点；空心点为预留功能建筑；步行时蓝色车标显示停车位置。地图范围外的标记不显示。
- 六档可视宽度：80 / 140 / 240 / 420 / 700 / 1200 米，默认 240 米。`+` 查看细节，`−` 查看更大范围；达到边界禁用对应按钮。
- 地图内鼠标滚轮可缩放，按钮适用于触屏；系统提供 MagnifyGesture 时也接收该手势。
- 标题、开篇过场、室内及对话隐藏，开篇恢复户外逃生控制后显示。

使用二维绘制，不新增 3D 摄像机、场景副本或持续渲染的子视口；地图内容约每 0.08 秒重绘一次。缩放仅改变小地图比例，不影响主镜头和角色操作。

实现：`scripts/ui/outdoor_minimap.gd`；入口：`scripts/main.gd`。

验证：`tools/verify_minimap.gd` 检查步行与驾驶跟随、箭头方向、中心投影、缩放按钮、滚轮、最大最小档位、室内与叙事显隐。`tools/capture_minimap.gd` 生成步行/驾驶的实际画面。手机触控体验和性能尚待真机验证。
