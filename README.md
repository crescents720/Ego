## 操作

开篇已接入“开始新游戏”：E / 画面按钮推进叙事，右上角可跳过过场；逃生段恢复移动控制，到房车右侧中部门上车。分镜、对白和模型处理说明见 [开篇设计](docs/opening_story.md)。

| 行为 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 / 驾驶 | WASD 或方向键 | 左下方向按钮 |
| 从右侧车门上车 | E 或 Space | “上车 E”或“侧门上车” |
| 驾驶中停车回到车内 | Space | “停车/起身” |
| 从车内右侧门下车 | 门旁按 E | “下车 E” |
| 进入房车或便利店 / 离开 / 搜刮 | E | 右侧“交互” |
| 近战攻击 | J | 右侧“攻击” |
| 房车升级 | Q | 右侧“改装” |

房车内部镜头：电脑端在场景空白处拖拽旋转、滚轮缩放；手机端单指拖拽旋转、双指捏合缩放。移动方向始终以当前镜头为准。靠近可交互家具时会出现轻微暖色高亮，按 E/“交互”可以查看模块状态。

户外右上角显示小地图，步行跟随小萤、驾驶跟随房车，箭头表示朝向，蓝色车标表示停放的房车。点击 `+` / `−` 放大缩小，电脑端也可在地图上使用滚轮；共有 80～1200 米的六档范围。实心彩色点标记家和便利店，空心点标记尚未建成的功能地块。进入室内、过场或对话时隐藏。

户外主画面也可缩放：在场景空白处滚动鼠标滚轮，或在空白处双指捏合；小地图下方的“画面缩放 / 拉近 + / 拉远 −”按钮可直接操作主镜头。步行和驾驶共享缩放偏好，并保留各自默认视野。小地图中的滚轮和 `+` / `−` 仍只影响小地图，二者互不影响。

## 小镇视角与便利店

室外步行和驾驶使用斜向 45°、俯视约 35°的平行投影镜头，呈现类似经典即时战略游戏的视角。步行方向依照屏幕；驾驶仍是前进、倒车和左右转向。房车内部继续使用原有可旋转镜头。室外建筑挡住小萤或房车时会自动变成半透明，离开遮挡范围后恢复。

便利店已整合在正常地图与首日流程中：开始新游戏，到店下车后，在正门按 E /“进店”进入；也可以步行到店。进店不受清理丧尸或任务阶段限制。

- 在货架之间行走，靠近彩色圆环，按 E / 交互搜刮。
- 四处物资分别提供食物 +3、饮水 +4、医疗用品 +2、维修材料 +5。
- 维修材料处保留哥哥的留言，触发返程目标；其余物资仍可继续搜索。
- 每处只能获取一次，离店再进入不会刷新。完成首日改装时，资源和已搜刮状态随进度保存。
- 回到入店位置按 E / 交互返回街道。

便利店使用用户提供的 `Supermarket.usdz` 转换版本，运行时加载约 1.58 万三角面的低模 GLB。商品改为共享贴图图集的陈列块，货架和墙体使用 11 个简单碰撞盒。转换说明和验证方法见 `docs/convenience_store.md`。

## 第三方资源

建筑、街道与部分街景来自 Quaternius 的 Downtown City MegaKit Standard，按 CC0 1.0 使用。完整许可文本位于 `licenses/Quaternius_Downtown_CC0.txt`。

当前只从 153 个源组件中挑选了 11 个小镇原型实际用到的模型及其纹理，避免把整包素材和大量无关导入缓存塞进项目。后续可以继续从原压缩包按区域增量加入模型。

普通街区现改用 Neberkenezer 的 CCity Building Set 1 中提取的 5 种低层建筑，源文件由用户提供，CC BY 4.0 出处及修改记录见 `licenses/CCity_Building_Set_1.txt`。Quaternius 资源保留供道路道具等使用。

房车内部是本项目的原创资产。用户提供的《少女前线2》宿舍模型包没有附带授权文件，因此只用于分析空间密度、色彩层次与生活化陈设，没有复制或分发其中的模型和贴图。

当前小萤外观使用用户提供的 `anime-girl.zip` 转换版本，原包同样没有作者、来源页面或许可证，仅限本地原型验证。正式发布前必须取得可验证的使用授权，或换成原创/明确许可的角色资产。原始模型是静态 OBJ，现使用轻量骨骼版本 `hotaru_combat.glb`，接入 Idle / Walk / Sit / Punch / Hit 动画。当前采用自动分区蒙皮，关节、裙摆和握方向盘姿态仍可继续精修。

## 房车与丧尸模型

房车使用用户提供的 Fleetwood Bounder USDZ 轻量转换版，丧尸使用用户提供的 Zombie USDZ。运行资产分别为 `assets/vehicles/bounder/bounder.glb` 和 `assets/characters/zombie/zombie_combat.glb`。丧尸源文件没有骨骼或动画，现已补充 18 关节骨骼及 Idle / Walk / Bite / Hit，保留追逐、受击与倒地。转换与交互设计见 `docs/actor_models.md`。

## 运行

1. 用 Godot 4.6.3（本机已验证）或兼容的更高版本导入根目录的 `project.godot`。
2. 按 F6/F5 运行主场景；窗口和触控界面已按 9:16 竖屏配置。
3. 首次启动选择“开始新游戏”。完成一级房车改装后会在本机保存进度。
